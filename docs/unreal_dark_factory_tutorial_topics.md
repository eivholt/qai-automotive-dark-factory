# Dark factory tutorial — topic ideas

- Companion outline to the handwritten tutorial; strongest project-specific techniques and findings first. These are useful applications and experiments, not claims of first invention.
- Status labels: **Live** = current demo behavior; **Experiment** = measured separately; **Open** = proposed or unfinished. Historical measurements retain their original model, prompt and scene scope.

- **One-token VLM classification instead of generated explanations — Live.** Read Reason2's first-token logits for G/A/R; check both conditional confidence and probability mass in the full vocabulary. A fast answer still requires image encoding and prompt prefill. [VLM deployment](evk_qairt_experiment.md)
- **One-token agent actions without fine-tuning — Live.** An unmodified Ministral chooses one A–H action token; application code translates it into a tool call. Require the unmasked vocabulary winner to be a valid action, rather than forcing the model to choose from an action-only distribution. [One-token controller](single_token_controller.md)
- **Remove generation of fragile tool parameters — Live.** The application supplies IDs, timestamps and fixed job arguments; the LLM selects the meaningful action. This reduces malformed calls and output-token cost while keeping the business policy editable. [Current tools](agent_demo_scope.md)
- **Optimize for an answer that never needs a second token — Experiment, incorporated into the streaming path.** Skip unused conversions of the KV cache into autoregressive decode layout and back; retain the first-token scoring result. [Prefill-only scoring](reason2_prefill_optimization.md)
- **Turn a fixed camera contract into a faster input processor — Live streaming building block.** Pack pixels directly into the model's patch layout and use a tiny normalization lookup table with reference-equivalent rounding. About 10.9× faster preprocessing in the isolated experiment; not 10.9× faster inference. [Fused preprocessing](inference_optimization_patterns.md)
- **Start processing before the camera has finished its scan — Live.** Upload and encode each real image during arm travel; preserve visual embeddings and DeepStack features. After image two, prefill one complete decoder block while the camera moves to image three. [Streamed inspection](streamed_reason2.md)
- **Streaming one joint question, rather than voting on separate answers — Live.** Preserve image order, positional encodings and the same KV sequence; publish one answer only after all three views arrive. Matched cadence replays saved roughly 0.45 seconds per inspection without changing recorded decisions or G/A/R probabilities. [Streaming measurements](streamed_reason2.md)
- **Prefill only information already known — Live and experiments.** Reuse the static policy prefix and prepare completed history while equipment moves; append the actual new observation when it arrives. Never guess a future camera result to make the cache faster. [Prefix preparation](dual_htp_pipeline.md), [controller caching](single_token_controller.md)
- **Treat the CPU runtime as an optimization target — Experiment.** Persistent worker pools, scheduling and thread synchronization can matter for short cached decisions; repeated whole-prompt benchmarks can hide those costs. Compare exact decisions as well as latency. [CPU tuning](ministral_cpu_tuning.md)
- **Verify accelerator placement instead of trusting a backend name — Experiment.** Trace actual HTP device handles, distinguish resident weights from KV/working memory, and measure contention with both models active. Separate HTP devices can reduce interference, but successful co-residency alone does not establish useful concurrency. [Device placement](npu_device_placement.md), [pipeline dependencies](dual_htp_pipeline.md)
- **The fastest isolated device may not make the best factory pipeline — Live choice informed by experiments.** Current default: Reason2 on the EVK NPU, Ministral on its CPU. Separate-HTP and EVK GPU candidates remain research paths; CPU/GPU/NPU choice must include reliability, model correctness and shared-resource contention. [Combined HTP experiment](streaming_dual_htp.md), [EVK GPU work](ministral_gpu.md)
- **Model export and quantization are behavioral changes to verify — Experiments and deployment.** Preserve adapted vision as well as decoder weights, tokenization, positional encodings and output scoring. The current Reason2 NPU deployment uses compiled FP16 vision/W8 text bundles; earlier Q4_0 GGUF trials introduced false accepts. [Export comparisons](evk_model_runtime.md), [compiled deployment](evk_qairt_experiment.md)

- **Semantically identical JSON can produce different agent decisions — Reproduced finding.** Changing field order changed a live choice, including after a full cache reset. Canonical field order is part of reproducible model input, not merely formatting. [History experiment](agent_history_reliability.md)
- **Make completed work explicit without prescribing the next action — Live.** Name jobs, keep a chronological completion history, remove model-visible IDs/timestamps and distinguish partial work from completion. Clearer history improves some cases but does not eliminate planning failures. [Named histories](agent_history_reliability.md)
- **Keep tools at the level of useful factory jobs — Live.** “Prepare panel,” “inspect temperatures” and “finish body” bundle fixed equipment choreography. The agent still chooses inspections, waits, retries and jobs; tool internals do not secretly make quality or branch decisions. [Eight-tool scope](agent_demo_scope.md)
- **Demonstrate agentic control without a hidden recipe enforcing success — Live.** Compare the LLM loop with the deterministic flow controller. An independent evaluator records bad choices without repairing or vetoing them; identity, cancellation and mechanical execution checks remain. [Control boundary](live_agent_control.md)
- **Move the actual agent harness onto the edge device — Live.** The IQ9 owns the prompt, conversation and dispatch loop; Unreal executes simulated equipment and reports actual results. F4 changes inference backends while orchestration remains on the EVK. [EVK harness](edge_agent_runtime.md)
- **Make asynchronous decisions belong to a particular physical moment — Live.** Bind images, prepared features and replies to body, request and cancellation epoch; reject stale work after pause or backend changes. Replay-safe event acknowledgements prevent duplicate execution during a live session; restart recovery remains explicitly limited. [Equipment protocol](edge_agent_runtime.md), [streaming state](streamed_reason2.md)

- **Thermal vision as a GPU surface field, not a recolored visible image — Live.** Evaluate mesh-local temperatures per pixel using depth/stencil and compact lookup textures; separate temperature, emissivity and reflected ambient radiation from visible lighting. CPU radiometry preparation avoids spectral integration for every pixel. [Thermal renderer](thermal_rendering.md)
- **Inspect heat conducted through a panel's visible surface — Live.** Sealant hidden under opaque steel warms the panel with a delayed contact response. The sensor sees that surface heat, not through-steel vision; temperature readiness remains a proxy, not proof of chemical cure. [Panel contact heat](panel_contact_heat.md)
- **Give thermal images spatial and temporal structure — Live, with separate procedural references.** Localized weld cores/halos, cooling tools, warm motors and residual cabinet heat replace uniformly colored parts. The procedural heat-transfer network is a separate approximation and is not applied wholesale to the hollow imported car body. [Motor heat](robot_motor_heat.md), [equipment heat](equipment_heat.md), [heat-transfer reference](thermal_heat_transfer.md)
- **Separate the audience's cinematic view from the model's instrument view — Live.** Independent observer/sensor NIR illumination; display-only thermal palettes and grain; Lumen/DLSS/roof lighting must not alter sensor PNGs. Verify byte-identical sensor output across observer settings. [Graphics isolation](observer_graphics.md), [NIR implementation](night_vision.md)
- **Render once for the HUD, read back only for inference — Live.** GPU render-target previews avoid unnecessary CPU round trips; bounded asynchronous readback and PNG encoding preserve capture identity. The inspection camera moves between views through the simulated arm joints. [Inspection capture](process_inspection.md), [GPU pipeline](bridge.md)

- **Use the simulator to produce controlled evidence, not answers for the agent — Live.** Randomize whole-body episodes, split datasets by episode, and vary nuisance temperatures/illumination independently of target labels. Ground truth labels training and audits but never enters live model requests. [Training](training.md), [current classifier](model_classification.md)
- **Choose adapter structure empirically — Live result, broader question still open.** A shared adapter handles presence, sealant and seating; a separate adapter handles weld cooling. Route by task stage, never by the predicted answer; preserve image, prompt and geometry provenance across training and deployment. [Adapter routing](model_classification.md)
- **Remove redundant scans before removing useful viewpoints — Measured contrasting outcomes.** One fresh three-view batch replaced two agreeing batches and reduced physical scan time. Dropping the third NIR view failed fresh tests; concurrent independent classifications also lost accuracy. [Batch comparison](consensus_experiment.md), [two-view experiment](two_view_npu_experiment.md), [fresh NIR check](streamed_reason2.md)
- **Measure the complete decision-to-action path — Cross-cutting lesson.** Distinguish preprocessing, vision encoding, prefill, first-token scoring, HTTP time, camera travel and physical cooling. Earlier decisions can cause more cooling retries, so a faster call need not shorten the assembly cycle. [Optimization evidence](inference_optimization_patterns.md)
- **Make optimization claims falsifiable — Cross-cutting method.** Compare tensors, tokens, winning actions and reported probabilities against a frozen reference; test actual rendered cycles and injected cancellation separately. Keep reused development accuracy, held-out accuracy and real-camera validation distinct. [Validation record](validation.md)
- **Recover an animated production cell from static purchased assets — Implemented foundation.** Headless Blender processing separates mesh islands, retains source ownership/materials and establishes joint-local pivots; production builders generate both runtime and editor previews. Useful authoring workflow, with authored motion rather than certified industrial kinematics. [Asset conversion](welding_cell_asset_import.md), [authoring structure](authoring_structure.md)
- **Keep failures and future branches visible — Open.** Sealant-continuity/reapplication and missing-frame scenarios could broaden agent decisions, but the coverage feasibility test failed and no compatible live coverage adapter exists. Evidence-invalidation mistakes in the current agent also remain topics for further work. [Coverage study](enhancement_second_pass.md), [known agent failures](agent_demo_scope.md)
