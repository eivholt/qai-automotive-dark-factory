# Welding temperatures and observer range

The fixed inspection camera maps apparent temperatures from 20 to 120 C into 8-bit grayscale. White means **120 C or hotter**, not that a weld cannot exceed 120 C. Keeping this narrow window preserves sensitivity near the 45 C adhesive and 55 C weld-release limits, and preserves the current prompts and LoRA input encoding.

The observer is now fixed at **0-120 C**. F10 and Xbox right-stick range switching are removed; K / Xbox D-pad left still changes white-hot, black-hot and iron palettes. The scale marks 0, 60 and 120+ C, with the plus sign indicating saturation. Fixed/model sensor previews retain **20-120 C**. Hotter physical weld cores still contribute their authored heat but saturate at the displayed endpoint. This uses the existing GPU post-process with no additional interactive capture or readback.

The former selectable 20-1600 C observer range and its results below are historical. Current `-DFThermalRangeSmoke` checks four fixed-range states (white, black, iron, restored white), saturated hot-weld pixels, exact fixed-sensor PNG parity, and the independent 0-120 observer mapping on un-clipped sensor pixels. It retains the existing filename `thermal_ranges.json`, with schema `darkfactory-thermal-display-smoke-v2`.

## Physical interpretation

Resistance spot welding melts a compact nugget at the interface between sheets. The water-cooled electrodes remove heat from the external surfaces, so the camera cannot directly measure a buried nugget through opaque steel. [TWI's description of surface marking](https://www.twi-global.com/technical-knowledge/faqs/faq-how-can-i-minimise-the-surface-marking-on-resistance-spot-welded-joints) distinguishes interface fusion from the cooler outer surfaces. A [published numerical and experimental study of hot-stamped boron steel](https://www.mdpi.com/2504-4494/5/1/10) uses 1480 C as its melting threshold; this is material-specific.

The process demo uses an intentionally enlarged **2 cm radius, 1600 C hot-metal core**, surrounded by the existing **12 cm radius, 420 C heat-affected halo**. The two spatial fields combine by maximum, preserving the hottest region without adding their temperatures. This is an illustrative surface hotspot for visible expulsion/exposed hot metal, not a measured external temperature or a view through the sheet to the nugget. Both fields heat and cool with the process clock. The compact core cools with a 0.65-second time constant, while the broader process halo uses a 5.0-second constant; the hot center fades quickly into the surrounding heat. The inspection arm never welds. Legacy preview fixtures retain their original 420 C heat recipe.

Physical surface temperature and apparent temperature differ because emissivity and reflected surroundings affect radiance. The renderer keeps sheet emissivity at 0.74; a 1600 C assigned core therefore need not appear as 1600 C on the apparent-temperature scale. The native radiometry calculation supports up to 2000 C. Imported profiles whose peak exceeds 500 C use two quadratic conversion segments, split at 100 C surface temperature, to retain accuracy near inspection thresholds. The extra fit reuses a spare row in the existing 88 KiB LUT; the GPU conditionally reads it for cool pixels on a hot panel. Profiles at or below 500 C and the procedural heat-exchange path retain their original conversion. The renderer remains a flat-response 8-14 micrometre approximation; it does not model a real detector's optics, exposure, calibration or high-temperature filters.

Separate measurement ranges are common in real instruments: the [FLIR A655sc specifications](https://www.flir.com/en-gb/products/a655sc/?model=55001-0305) list low and medium ranges and an optional range up to 2000 C. The earlier high-range observer experiment illustrated that distinction. The current demo fixes its observer to 0-120 C and keeps model sensor encoding at 20-120 C.

## Model and data continuity

The model receives the existing 448 x 256 grayscale images and unchanged stage prompts. Temperatures above the inspection range saturate. No high-range palette, HUD annotation or scene temperature is supplied to the model. Hotspots and cooling timing have changed, so earlier model accuracy numbers remain tied to their original datasets. Validate current rendered coverage and model-gated behavior separately; do not relabel old captures as evidence for this heat recipe.
